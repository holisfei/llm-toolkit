# 并发执行 + 配对

Q: gather 并发执行多工具,返回 list 顺序由什么决定?ToolResult 配对该靠什么?
A: 返回顺序 = 传入顺序,不是完成顺序(实验:fast 先完成但 slow 仍排前)。配对不能靠"谁先回来配谁",要靠 tool_use_id——而且配对应在每个 dispatch_one 协程内部就地用 call.id 绑死,不留到外层按位置对。

Q: 为什么 except TypeError: return "参数错误" 危险?异常类型和异常原因什么关系?
A: TypeError 不只在"参数名/数量错"时抛,工具函数体内部任何类型错(如 None+str)也抛。把后者误诊成"模型参数错"会:误导模型改参重试→死循环,真 bug(工具内部)被假诊断永久掩盖。异常的"类型"是机制层信息,不携带"谁的错"这种语义层信息。错误处理第一原则:不知道原因就如实转述,别编造归因。
